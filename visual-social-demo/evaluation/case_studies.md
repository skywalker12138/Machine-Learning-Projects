# 案例研究：成功推荐 vs 失败案例（演示）

本文件用于课程/答辩演示：**不等价于真实平台的配对效果**，仅展示「视觉风格匹配度 / 兴趣线索相似度 / 偏好满足度」三类信号如何在排序与解释中出现。

## 成功案例（>=5）

### S1 — `u001（阿野）` → `u002（小霖）`
- **设定**：两者均为户外/露营相关兴趣与自然场景偏好。
- **期望**：相似模式下视觉向量接近，兴趣标签重合度高。
- **观察点**：CLIP 聚合向量余弦偏高；解释模板应突出「户外徒步/露营」类视觉提示。

### S2 — `u005（辰辰）` → `u019（橙子）`
- **设定**：运动场景与机能穿搭线索。
- **期望**：运动相关视觉提示在两者的 TOP 列表中同时出现。

### S3 — `u004（Mio）` → `u025（可可）`
- **设定**：咖啡馆/安静室内与街拍胶片元素。
- **期望**：室内咖啡场景提示重合；兴趣标签部分重合。

### S4 — `u023（像素）` → 同类桌面 RGB / 电竞线索用户池（如 `u009` 互补偏好不一定最优）
- **设定**：强调桌面搭建与电竞 RGB。
- **期望**：画面叙事一致的候选排序靠前。

### S5 — `u009（格子）`（互补模式）→ `u001（阿野）` 或其他强户外用户
- **设定**：查询用户偏好文本明确希望「办公桌极简 ↔ 户外徒步」互补。
- **期望**：互补模式权重更高，`complement_bonus` 对“适度差异”给出正向贡献（不等同于越大越好）。

## 失败案例（>=3）

### F1 — `u031（边界案例A）`
- **失败原因**：偏好描述极度含糊，CLIP 文本对齐信号弱，排序更像「向量邻近噪声」。
- **教学意义**：需要更强的偏好结构化（关键词抽取、交互式补充）。

### F2 — `u032（边界案例B）`
- **失败原因**：查询图像叙事集中在音乐节/霓虹/涂鸦，但偏好文本要求「古典音乐会正装」互补对象——数据集中未必存在强线索候选。
- **教学意义**：互补匹配依赖候选仓多样性；文本偏好与真实图像叙事冲突时会降低 `preference_fit`。

### F3 — YOLO 缺失或检测稀疏导致的保守下调
- **失败原因**：部分候选缺少检测框，`penalty` 轻微下调分数；解释中会出现“物体检测线索不足”。
- **教学意义**：检测分支应与 CLIP 分支互补；Demo 可用但不保证鲁棒。

## 如何在 Demo 中复现

1. `streamlit run app/demo.py`
2. 侧边栏选择查询用户 `u001`、`u031`、`u032` 等观察榜单变化。
3. 打开「相似度矩阵」核对向量层面的邻近关系是否符合直觉。
4. 使用 👍/👎 触发反馈重排，观察“反馈系数”列变化。
