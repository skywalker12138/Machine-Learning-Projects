# 基于 ResGCN 的电力系统小干扰稳定预测模型

本项目通过 PyTorch Geometric 实现了一种改进的图卷积神经网络（ResGCN），专门用于电力系统小干扰稳定性（Small Signal Stability, SSS）指标的快速回归预测。

## 1. 背景概述：什么是小干扰稳定？
**小干扰稳定性（Small Signal Stability）** 指的是电力系统在受到小扰动（如负荷的连续微小波动、线路阻抗的轻微变化）后，系统各同步发电机保持同步运行的能力。
* **传统分析法：** 通常依赖于对系统状态方程矩阵的特征值分析。这种方法在电网规模扩大、含高比例新能源接入时，计算维度会呈指数级增长，难以满足实时监控的需求。
* **本项目的意义：** 利用深度学习的强大拟合能力，建立电网拓扑与稳定指标之间的映射关系，实现毫秒级的稳定性评估。

## 2. 为什么选择图卷积网络 (GCN)？
### 2.1 拓扑感知 (Topology-Aware)
电力系统本质上是一个物理拓扑图（总线为节点，线路为边）。传统的神经网络（如 MLP）将电网参数视为独立的向量，忽略了节点间的物理连接关系。GCN 能够直接在图结构上进行计算，捕获电力电子设备间的相互耦合作用。

### 2.2 信息传递机制 (Message Passing)
小干扰的传播具有明显的空间相关性。GCN 通过“消息传递”机制，让每个节点聚合其邻居节点的状态，从而学习到全局或局部的动态特征。

### 2.3 残差连接 (Residual Learning) 的优势
深层图神经网络容易出现“过平滑（Over-smoothing）”现象，即所有节点的特征趋于一致。本项目引入残差连接，允许原始特征跨层传递，确保模型在提取深层抽象特征的同时，保留底层物理特征。

## 3. 模型结构细节详述
模型采用 **ResNet-style Graph Convolutional Network** 架构，主要包含以下层级：

* **输入映射层 (Linear Input Mapping)：** 由于原始特征维度可能与隐藏层维度不一致，首先通过一个线性层 `self.lin_in` 将节点特征投影到高维空间（128维），作为残差连接的基准。
* **残差图卷积块 (3-Layer GCN Blocks)：**
    包含三层连续的 `GCNConv` 层。每一层的输出都会通过 ReLU 激活，并与上一层的输入进行**向量加法（Residual Addition）**。这保证了梯度的顺畅传播，解决了深层网络难以训练的问题。
* **全局均值池化 (Global Mean Pooling)：**
    为了从节点级特征（Node-level）提取出系统级特征（Graph-level），使用池化操作对所有节点的隐藏状态求均值，形成代表整个电网状态的特征向量。
* **多层感知机解码器 (MLP Decoder)：**
    包含 4 个全连接层（128 -> 64 -> 32 -> 输出维度）。
    * 引入 **Dropout (0.5)** 机制，在训练过程中随机使 50% 的神经元失活，极大地增强了模型的泛化能力，防止在小规模样本上过拟合。
    * 层间使用 ReLU 激活函数保持非线性表达能力。

## 4. 实验结果
在独立测试集上的表现如下（原始尺度）：
* **RMSE (均方根误差):** 0.0032
* **MAAPE (平均反正切绝对百分比误差):** 3.67%
* **SMAPE (对称平均绝对百分比误差):** 3.72%
